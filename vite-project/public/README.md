# 🖼️ Galerie d'image et d'art

Bienvenue sur le projet **Galerie d'image et d'art**, une plateforme d'exposition d'affiches d'œuvres d'art créée en React.js. Ce projet a été réalisé en collaboration par **Stéphane** et **Harish**.

## 🚀 Démarrage Rapide

Suivez ces étapes simples pour cloner et lancer l'application sur votre machine locale.

### Prérequis

Assurez-vous d'avoir installé les outils suivants :

* **Node.js** (version LTS recommandée)
* **npm** (inclus avec Node.js)

### Installation et Lancement

1.  **Clonage du Dépôt**
    Ouvrez votre terminal et clonez le dépôt Git :
    ```bash
    git clone [https://github.com/bharishh/Projet-React](https://github.com/bharishh/Projet-React)
    ```
    Puis, accédez au dossier du projet :
    ```bash
    cd [vite-project]
    ```

2.  **Accès au Dossier de l'Application**
    L'application front-end se trouve dans le sous-dossier `vite-project`. **Vous devez vous y placer pour travailler.**

    Dans votre terminal ou dans le terminal de VS Code :
    ```bash
    cd vite-project
    ```

3.  **Installation des Dépendances**
    Installez toutes les dépendances du projet :
    ```bash
    npm install
    ```

4.  **Lancement du Serveur de Développement**
    Démarrez l'application :
    ```bash
    npm run dev
    ```

Le lien pour accéder à la galerie (généralement `http://localhost:5173/`) s'affichera dans votre terminal.

## ⚠️ Dépannage Important

Si la commande `npm run dev` ne fonctionne pas, **vérifiez toujours que vous êtes bien positionné dans le dossier `vite-project`** avant de relancer la commande.
